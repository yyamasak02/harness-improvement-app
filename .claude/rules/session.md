# セッション運用

## 開始・再開時（必ず最初に）
1. `bash scripts/status.sh`（SessionStart フックでも自動表示される）。`resume` skill に従って状態を判定する。
2. `docs/handoff.md` は**参考情報**。git・PR・issue の現実と食い違ったら現実を信じる。

## 引き継ぎメモ（`docs/handoff.md`）を更新するタイミング
- PR をマージしたとき（目標・進捗・次の一手が変わる）
- フェーズが変わったとき（実装 → レビュー → リリース準備 など）
- 人の作業待ちになった／ブロッカーが出たとき
- 作業を止める・長い待ち（CI・レビュー）に入る前
- メモは短く保つ（目標・進捗の要約・次の一手・未解決の注意）。履歴の詳細は git と issue に任せる。
- 更新は通常の PR に含めてよい（`docs:` だけの PR は不要）。`status.sh` は 8 コミット以上更新が無いと警告する。

## 書いてはいけないこと
- 秘密情報・個人情報（メールアドレス等）
- 現実から導けない推測（「たぶん通る」など）。確認済みの事実だけを書く
